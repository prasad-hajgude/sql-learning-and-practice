#OPERATORS-SQL operators are symbols or keywords used to perform operations on data in a database.
They help us filter records, compare values, perform calculations, and combine conditions.

ARITHMETIC OPERATORS
OPERATORS (+,-,*,%)
COMPARISON(=,<>,>,<,>=,<=)
LOGICAL(AND , OR , NOT)
SQL OPERATORS(IN , BETWEEN, LIKE, ISNULL

Arithmetic operator- used to perform mathematical operation 

 --- Addition
SELECT marks + 5 AS new_marks
FROM Student;

-- Subtraction
SELECT marks - 5 AS reduced_marks
FROM Student;

-- Multiplication
SELECT marks * 2 AS double_marks
FROM Student;

-- Division
SELECT marks / 2.0 AS half_marks
FROM Student;

-- Modulus (remainder)
SELECT marks % 2 AS remainder
FROM Student;


3. Comparison Operators
Used to compare values. They are commonly used in the WHERE clause.
Operator	Meaning	Example
=	Equal to	WHERE marks = 80
<>	Not equal to	WHERE marks <> 80
!=	Not equal to	WHERE marks != 80
>	Greater than	WHERE marks > 80
<	Less than	WHERE marks < 80
>=	Greater than or equal to	WHERE marks >= 80
<=	Less than or equal to	WHERE marks <= 80

4)Logical Operators
Logical operators help you apply multiple conditions.
AND
Both conditions must be true.
SELECT *
FROM Student
WHERE marks >= 70 AND marks <= 90;


Returns students whose marks are between 70 and 90, inclusive.
OR
At least one condition must be true.
SELECT *
FROM Student
WHERE name = 'Amit' OR name = 'Rahul';


Returns Amit or Rahul.
NOT
Reverses a condition.
SELECT *
FROM Student
WHERE NOT marks >= 80;


Returns students with marks below 80, excluding rows where marks are NULL.
AND vs OR
Suppose the table contains marks of 60, 75 and 90.
- marks >= 70 AND marks <= 80 → returns 75.
- marks < 70 OR marks > 80 → returns 60 and 90.


Special Operators
These operators are very important for SQL assignments and interviews.
IN
Checks whether a value matches any value in a list.
SELECT *
FROM Student
WHERE name IN ('Amit', 'Priya');


Equivalent to:
WHERE name = 'Amit' OR name = 'Priya'


NOT IN
Excludes the listed values.
SELECT *
FROM Student
WHERE name NOT IN ('Amit', 'Priya');


BETWEEN
Checks whether a value falls within a range. The endpoints are included.
SELECT *
FROM Student
WHERE marks BETWEEN 70 AND 90;


Returns students with marks from 70 through 90.
LIKE
Searches for a pattern in text.
Pattern	Meaning
'A%'	Starts with A
'%a'	Ends with a
'%it%'	Contains it
'_a%'	Second character is a
Example:
SELECT *
FROM Student
WHERE name LIKE 'A%';


Returns names starting with A.
% matches zero or more characters, while _ matches exactly one character in standard SQL pattern matching.
IS NULL
Checks whether a value is missing (NULL).
SELECT *
FROM Student
WHERE marks IS NULL;


To find records where marks are present:
SELECT *
FROM Student
WHERE marks IS NOT NULL;


Important: Never use marks = NULL. Use IS NULL instead.
6. Set Operators
Set operators combine the results of two SELECT queries.
Operator	Purpose
UNION	Combines results and removes duplicates
UNION ALL	Combines results and retains duplicates
INTERSECT	Returns rows common to both results
EXCEPT	Returns rows from the first result that are absent from the second
Example:
SELECT city FROM Student
UNION
SELECT city FROM Employee;
